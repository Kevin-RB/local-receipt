Receipts, structured

Photograph a receipt. Then ask about it.

possum reads the photo with a local vision model, parses it into line items, totals and categories, and keeps the image. Everything lands in one place you can query in plain language — no cloud account, no receipt-tracking subscription.

What it does

Three surfaces, one pile of receipts

The chat is the front door. Receipts and Overview are there when you want to see the data rather than ask for it.

Chat

"What did I spend on groceries last month?" The agent calls owner-scoped tools over your receipts and answers in a sentence, with the numbers it actually found.

Receipts

Every receipt with its image, its line items and where it was bought. Edit anything the extraction got wrong; the correction is stored.

Overview

Spending over time, by merchant, and by category — all read off the same rows the chat queries.

How it works

Upload, extract, categorize, ask

Each stage is durable and re-runnable, so a failure resumes where it stopped instead of starting the whole thing again.

Upload Your browser writes the image straight to storage over a presigned URL.
Extract A vision model transcribes it; a second pass parses that into a fixed contract.
Categorize Each line item gets a leaf category from a shared taxonomy. Derived, so it can be redone.
Ask The chat agent reads it back through owner-scoped tools.
